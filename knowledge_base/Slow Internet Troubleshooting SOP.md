# Slow Internet Troubleshooting SOP

**Document Type:** Customer Support SOP  
**Document ID:** KB-NET-002  
**Version:** 1.0  
**Status:** Active  
**Applies To:** Residential Internet Customers

## 1. Purpose

This SOP defines the standard troubleshooting process for customers who report slow or degraded internet performance while their internet service is still available.

## 2. Scope

Use this SOP for complaints such as:

- Internet is slower than usual.
- Websites or applications load slowly.
- Video streaming frequently buffers.
- Downloads are slower than expected.
- Customer reports inconsistent internet performance.

Do not use this SOP for a complete internet outage. Complete outages should follow the Internet Outage Complaint Policy.

## 3. Initial Assessment

Collect the following information when available:

- Customer ID
- Complaint ID
- Approximate time the problem started
- Number of connected devices
- Whether the problem affects all devices or only one
- Whether the problem occurs continuously or intermittently
- Whether the customer is using Wi-Fi or a wired connection

The assistant must not assume missing information.

## 4. Basic Troubleshooting

Recommended steps may include:

1. Restart the router or gateway.
2. Move the device closer to the Wi-Fi router.
3. Check whether multiple devices are experiencing the same problem.
4. Disconnect devices that are not currently required.
5. Test the connection again after restarting the gateway.
6. If possible, compare Wi-Fi performance with a wired connection.

Troubleshooting should be relevant to the customer's reported symptoms.

## 5. Wi-Fi-Specific Issues

If the problem occurs only on Wi-Fi:

- Check the distance between the device and gateway.
- Check whether walls or other obstacles may affect the signal.
- Check whether multiple devices are using the connection.
- Recommend testing another device when appropriate.

Do not state that Wi-Fi interference is the confirmed cause unless an authorized diagnostic system confirms it.

## 6. Escalation

Consider escalation when:

- Troubleshooting does not resolve the issue.
- Multiple devices continue to experience degraded performance.
- The customer repeatedly reports the same unresolved issue.
- Specialized network investigation is required.

## 7. Response Guidelines

The assistant should:

- Acknowledge the reported slow performance.
- Explain troubleshooting steps clearly.
- Avoid claiming a specific technical cause without evidence.
- Avoid promising a specific resolution time.
- Recommend escalation when the issue cannot be resolved through the supported troubleshooting process.

## 8. Example

**Customer:**  
"My internet works but everything is extremely slow."

**Classification:**  
`SLOW_INTERNET`

**Recommended handling:**  
Follow the slow-internet troubleshooting process rather than the complete-outage process.
